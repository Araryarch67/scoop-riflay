# Scoop bucket for Riflay

[Riflay](https://github.com/Araryarch67/Riflay) is a music player for your own music and YouTube Music, with hi-fi audio.

```powershell
scoop bucket add riflay https://github.com/Araryarch67/scoop-riflay
scoop install riflay/riflay
```

`bucket/riflay.json` is updated by Riflay's release workflow; change it in the Riflay
repository (`packaging/scoop/riflay.json`), not here.
